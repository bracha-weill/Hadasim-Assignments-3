# K3s – Lightweight Kubernetes

## What is K3s?
K3s is a lightweight, fully compliant Kubernetes distribution developed by Rancher (now part of SUSE).  
It is designed to be easy to install, require minimal resources, and run Kubernetes in environments where a full Kubernetes setup would be too heavy.

---

## When should it be used?
K3s should be used when:
- You need Kubernetes but have **limited CPU, memory, or storage**
- You want a **simple and fast setup**
- You are working on **development, testing, or edge deployments**
- You want Kubernetes on a **single node or small cluster**

---

## Where can it be used?
K3s can be used in:
- Edge devices and IoT environments
- Local development machines
- CI/CD pipelines
- Small servers or virtual machines
- ARM-based systems (like Raspberry Pi)
- On-premise or cloud environments

---

## Why should I use it?
You should use K3s because:
- It is **lightweight** and fast
- It has **low resource consumption**
- It is **easy to install and maintain**
- It is **fully Kubernetes-compatible**
- It removes unnecessary components while keeping core functionality

K3s makes Kubernetes accessible in places where traditional Kubernetes would be impractical.
