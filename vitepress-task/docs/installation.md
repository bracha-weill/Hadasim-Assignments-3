# 📘 Auto CleanCode — Installation Guide

Welcome to the installation guide for **Auto CleanCode**, the tool that keeps your code clean, elegant, and efficient.

---

## 🔧 System Requirements
- Operating System: Windows, macOS, or Linux  
- Code Editor: VS Code, JetBrains IDEs, or any editor supporting extensions  
- Internet connection for initial setup  
- Recommended: Node.js or Python installed (optional for advanced features)

---

## 🪄 Installation Steps

### 1️⃣ Download the Extension
Download the Auto CleanCode extension from the official marketplace of your preferred editor.

### 2️⃣ Install the Extension
Open your editor and install the downloaded extension file:  
- **VS Code**: `Extensions → Install from VSIX`  
- **JetBrains**: `Settings → Plugins → Install Plugin from Disk`

### 3️⃣ Activate Auto CleanCode
After installation, restart your editor.  
Auto CleanCode will appear in your sidebar or toolbar.

### 4️⃣ Run Your First Scan
Open any project and click **“Run Clean Scan”**.  
The tool will analyze your code and suggest improvements instantly.

---

## 🧪 Optional: Enable Advanced Features
- Enable AI‑powered suggestions  
- Configure language‑specific rules

---

## 🎉 You're Ready!
Auto CleanCode is now fully installed and ready to help you write cleaner, smarter code.
